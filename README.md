# Apex Horizon Motors - Modern Light Auto Gallery & AI Concierge

A modern, light editorial web application for **Apex Horizon Motors**, built using **Vue 3**, Tailwind CSS, and FontAwesome. Features a **Cinematic Pre-Landing Moving Car Intro**, authentic real-world production cars with verified VINs, live side-by-side vehicle comparisons, dynamic lease/finance calculators, and an interactive **24/7 AI Concierge Bot (Aura)**.

---

## 🎬 Cinematic Pre-Landing Intro
- **Independent Pre-Landing Presentation**: The moving car sequence has been removed from the main page flow and is now an intro screen that plays **before** entering the landing page.
- **Cinematic Drive-Through**: A sports car accelerates into view across the screen with spinning multi-spoke wheels, illuminated projector LED headlights, and an animated live digital speedometer counting up from 0 to 85 MPH.
- **Seamless Transition**: After 3 seconds (or instantly upon clicking **"Enter Showroom"**), the intro screen smoothly scales and fades out, revealing the pristine light luxury landing page.
- **Replay Anytime**: A discreet "Replay Intro" button in the top notification bar allows visitors to re-watch the driving sequence whenever they want.

---

## 🎨 Modern Light Luxury Aesthetic
- **Pristine Color Palette**: Clean white cards (`#ffffff`) on warm porcelain backgrounds (`#f8fafc`) with subtle slate borders and electric sapphire accents.
- **Reactive Architecture (Vue 3)**: Instantaneous search, dynamic category filtering without page reloads, smooth transitions, and live state synchronization.
- **Side-by-Side Comparison Tray**: Select up to 3 real cars and compare technical specs (HP, 0-60, MPG/Range, Transmission, Drivetrain, Price, VIN) in a clean comparison table.
